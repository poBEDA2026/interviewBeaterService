Модуль аутентификации и авторизации

users

Пользователи системы с JWT-аутентификацией

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор пользователя
UQ email VARCHAR(255) NOT NULL Email для входа (уникальный)
password_hash VARCHAR(255) NOT NULL BCrypt-хеш пароля
role VARCHAR(20) NOT NULL, DEFAULT 'USER' Роль: USER или ADMIN
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания аккаунта
updated_at TIMESTAMP NOT NULL, AUTO UPDATE Время последнего обновления

refresh_tokens

Refresh-токены JWT с возможностью отзыва

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор токена
FK user_id BIGINT NOT NULL, CASCADE DELETE Ссылка на пользователя
UQ token VARCHAR(500) NOT NULL Хеш токена
expires_at TIMESTAMP NOT NULL Время истечения токена
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания токена
revoked_at TIMESTAMP NULLABLE Время отзыва токена (NULL = активен)
Связи:
• users.id → refresh_tokens.user_id (CASCADE DELETE)
• Индекс: idx_refresh_tokens_user_expires (user_id, expires_at)

Модуль каталога вопросов

categories

Категории вопросов (Core Java, Spring, и т.д.)

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор категории
UQ name VARCHAR(100) NOT NULL Название категории (уникальное)
description TEXT NULLABLE Описание категории
display_order INT NOT NULL, DEFAULT 0 Порядок отображения
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания

tags

Теги для гибкой категоризации вопросов

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор тега
UQ name VARCHAR(50) NOT NULL Название тега (уникальное)
color VARCHAR(7) NULLABLE Цвет для UI (hex)
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания

questions

Основная таблица вопросов - поддерживает общий банк и личные вопросы

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор вопроса
title VARCHAR(500) NOT NULL Заголовок вопроса
answer TEXT NULLABLE Ответ в формате Markdown
FK category_id BIGINT NOT NULL Ссылка на категорию
difficulty VARCHAR(20) NOT NULL, CHECK IN ('EASY','MEDIUM','HARD','EXPERT') Сложность вопроса
FK author_id BIGINT NULLABLE, SET NULL DELETE Автор (NULL = общий банк)
is_public BOOLEAN NOT NULL, DEFAULT true Общий (true) или личный (false)
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания
updated_at TIMESTAMP NOT NULL, AUTO UPDATE Время последнего обновления
Связи:
• categories.id → questions.category_id
• users.id → questions.author_id (SET NULL DELETE)
• Индексы: idx_questions_category, idx_questions_difficulty, idx_questions_author

question_tags

Junction-таблица для отношения многие-ко-многим

Поле Тип Ограничения Описание
PK FK question_id BIGINT NOT NULL, CASCADE DELETE Ссылка на вопрос
PK FK tag_id BIGINT NOT NULL, CASCADE DELETE Ссылка на тег
Связи:
• questions.id → question_tags.question_id (CASCADE DELETE)
• tags.id → question_tags.tag_id (CASCADE DELETE)
• Индекс: idx_question_tags_tag (tag_id)

Модуль интервального повторения (SRS)

review_schedules

Изменяемое состояние алгоритма SM-2 - одна запись на пару пользователь-вопрос

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор расписания
FK user_id BIGINT NOT NULL, CASCADE DELETE Ссылка на пользователя
FK question_id BIGINT NOT NULL, CASCADE DELETE Ссылка на вопрос
interval_days INT NOT NULL, DEFAULT 0 Интервал до следующего повторения (дни)
easiness_factor DECIMAL(3,2) NOT NULL, DEFAULT 2.50, CHECK >= 1.30 Коэффициент лёгкости SM-2 (EF)
repetitions INT NOT NULL, DEFAULT 0 Количество успешных повторений
next_review_date TIMESTAMP NOT NULL Дата следующего повторения
last_review_date TIMESTAMP NULLABLE Дата последнего повторения
status VARCHAR(20) NOT NULL, CHECK IN ('ACTIVE','SUSPENDED','MASTERED') Статус расписания
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания
updated_at TIMESTAMP NOT NULL, AUTO UPDATE Время последнего обновления
Связи:
• users.id → review_schedules.user_id (CASCADE DELETE)
• questions.id → review_schedules.question_id (CASCADE DELETE)
• Уникальный ключ: (user_id, question_id)
• Индексы: idx_review_schedules_due, idx_review_schedules_user_status

review_history

Неизменяемый журнал всех повторений - источник истины для статистики

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор записи
FK review_schedule_id BIGINT NOT NULL, CASCADE DELETE Ссылка на расписание
FK user_id BIGINT NOT NULL Ссылка на пользователя
FK question_id BIGINT NOT NULL Ссылка на вопрос
grade INT NOT NULL, CHECK BETWEEN 0 AND 5 Оценка SM-2 (0-5)
review_date TIMESTAMP NOT NULL, DEFAULT now() Дата повторения
interval_before INT NOT NULL Интервал ДО повторения
interval_after INT NOT NULL Интервал ПОСЛЕ повторения
ef_before DECIMAL(3,2) NOT NULL EF ДО повторения
ef_after DECIMAL(3,2) NOT NULL EF ПОСЛЕ повторения
repetitions_before INT NOT NULL Повторения ДО
repetitions_after INT NOT NULL Повторения ПОСЛЕ
time_taken_seconds INT NULLABLE Время ответа в секундах (опционально)
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания записи
Связи:
• review_schedules.id → review_history.review_schedule_id (CASCADE DELETE)
• users.id → review_history.user_id
• questions.id → review_history.question_id
• Индексы: idx_review_history_user_date, idx_review_history_schedule, idx_review_history_question

Модуль статистики

user_statistics

Денормализованная статистика на уровне пользователя

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор
FK UQ user_id BIGINT NOT NULL, CASCADE DELETE Ссылка на пользователя (уникальная)
total_questions INT NOT NULL, DEFAULT 0 Общее количество вопросов
questions_due INT NOT NULL, DEFAULT 0 Вопросов к повторению
questions_mastered INT NOT NULL, DEFAULT 0 Вопросов освоено
total_reviews INT NOT NULL, DEFAULT 0 Общее количество повторений
average_grade DECIMAL(3,2) NULLABLE Средняя оценка
current_streak_days INT NOT NULL, DEFAULT 0 Текущая серия (дни)
longest_streak_days INT NOT NULL, DEFAULT 0 Самая длинная серия
last_review_date TIMESTAMP NULLABLE Дата последнего повторения
updated_at TIMESTAMP NOT NULL, AUTO UPDATE Время последнего обновления
Связи:
• users.id → user_statistics.user_id (CASCADE DELETE)
• Обновляется через доменные события QuestionReviewedEvent

category_statistics

Статистика по категориям для каждого пользователя

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор
FK user_id BIGINT NOT NULL, CASCADE DELETE Ссылка на пользователя
FK category_id BIGINT NOT NULL Ссылка на категорию
questions_in_category INT NOT NULL, DEFAULT 0 Вопросов в категории
questions_due INT NOT NULL, DEFAULT 0 Вопросов к повторению
questions_mastered INT NOT NULL, DEFAULT 0 Вопросов освоено
total_reviews INT NOT NULL, DEFAULT 0 Общее количество повторений
average_grade DECIMAL(3,2) NULLABLE Средняя оценка
updated_at TIMESTAMP NOT NULL, AUTO UPDATE Время последнего обновления
Связи:
• users.id → category_statistics.user_id (CASCADE DELETE)
• categories.id → category_statistics.category_id
• Уникальный ключ: (user_id, category_id)

daily_statistics

Ежедневная статистика для отслеживания серий и графиков активности

Поле Тип Ограничения Описание
PK id BIGINT NOT NULL, AUTO INCREMENT Уникальный идентификатор
FK user_id BIGINT NOT NULL, CASCADE DELETE Ссылка на пользователя
date DATE NOT NULL Дата записи
reviews_completed INT NOT NULL, DEFAULT 0 Завершённых повторений
new_questions_added INT NOT NULL, DEFAULT 0 Добавлено новых вопросов
questions_mastered INT NOT NULL, DEFAULT 0 Освоено вопросов
average_grade DECIMAL(3,2) NULLABLE Средняя оценка
time_spent_minutes INT NOT NULL, DEFAULT 0 Время в минутах
created_at TIMESTAMP NOT NULL, DEFAULT now() Время создания записи
Связи:
• users.id → daily_statistics.user_id (CASCADE DELETE)
• Уникальный ключ: (user_id, date)
• Индекс: idx_daily_statistics_user_date (user_id, date DESC)

🔗 Ключевые индексы

Частичные индексы (Partial Indexes)

Индекс Таблица Условие Назначение
idx_questions_author questions WHERE author_id IS NOT NULL Личные вопросы пользователей
idx_review_schedules_due review_schedules WHERE status = 'ACTIVE' Активные вопросы к повторению
idx_questions_public questions WHERE is_public = true Общий банк вопросов
idx_refresh_tokens_revoked refresh_tokens WHERE revoked_at IS NULL Активные токены

Составные индексы (Composite Indexes)

Индекс Таблица Колонки Поддерживаемые запросы
idx_questions_category_difficulty questions (category_id, difficulty, is_public) Фильтр по категории и сложности
idx_review_schedules_user_due review_schedules (user_id, next_review_date) Вопросы пользователя к повторению
idx_review_schedules_user_status review_schedules (user_id, status) Вопросы пользователя по статусу
idx_refresh_tokens_user_expires refresh_tokens (user_id, expires_at) Очистка истёкших токенов

🎯 CHECK Constraints

Ограничение Таблица Условие Защита от
chk_questions_difficulty questions difficulty IN ('EASY','MEDIUM','HARD','EXPERT') Некорректной сложности
chk_review_schedules_status review_schedules status IN ('ACTIVE','SUSPENDED','MASTERED') Некорректного статуса
chk_review_schedules_easiness review_schedules easiness_factor >= 1.30 EF меньше минимума SM-2
chk_review_history_grade review_history grade BETWEEN 0 AND 5 Оценки вне диапазона SM-2

🔄 Триггеры

Триггер Таблица Событие Функция
trg_users_updated_at users BEFORE UPDATE update_updated_at_column()
trg_questions_updated_at questions BEFORE UPDATE update_updated_at_column()
trg_review_schedules_updated_at review_schedules BEFORE UPDATE update_updated_at_column()
trg_user_statistics_updated_at user_statistics BEFORE UPDATE update_updated_at_column()
trg_category_statistics_updated_at category_statistics BEFORE UPDATE update_updated_at_column()

Функция update_updated_at_column() автоматически устанавливает updated_at = CURRENT_TIMESTAMP при каждом UPDATE.

Ключевые моменты для собеседования

🏗️ Архитектура

  • CQRS паттерн: Изменяемое состояние + неизменяемый журнал
  • Доменные события: Статистика обновляется асинхронно
  • Готовность к микросервисам: Spring Events → Kafka путь эволюции

⚡ Производительность

  • Частичные индексы: Индексируем только релевантные строки
  • Денормализованная статистика: Предварительно вычисленные агрегаты
  • Составные индексы: Соответствие паттернам запросов

🔒 Безопасность

  • Каскады внешних ключей: Кодирование бизнес-правил
  • Refresh-токены JWT: Поддержка базой данных для отзыва
  • Ограничения целостности: CHECK constraints и внешние ключи

✅ Целостность данных

  • Строковые enum'ы: CHECK-ограничения для безопасности
  • Триггеры: Автоматическое обновление временных меток
  • Ссылочная целостность: Внешние ключи на всех отношениях

🔮 Будущее-устойчивость

  • Гибкость алгоритма: Журнал истории позволяет A/B-тестирование
  • Мультиарендность: Общие vs личные вопросы
  • Наблюдаемость: Полный журнал аудита в review_history
